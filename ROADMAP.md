# StellarTrust Roadmap

## MVP (Current)

- landing and onboarding view
- project and milestone management UI
- Stellar Testnet payment foundation
- transaction lookup and explorer integration
- wallet and activity overview
- contributor-friendly documentation and issue planning

## Planned

These items are future contributor tasks and are intentionally not part of the current MVP implementation.

1. Authentication and session persistence
2. Prisma-backed project persistence
3. Prisma-backed milestone persistence
4. Role-based authorization
5. Soroban escrow contract
6. Automated milestone payment release
7. Dispute resolution workflow
8. Notifications and activity events
9. Freelancer earnings and payment history
10. Stellar payment integration tests

See [docs/github-issues.md](docs/github-issues.md) for the full issue backlog and contributor-ready task definitions.

## Contributor Guidance

The MVP intentionally leaves the larger multi-party payment, persistence, authorization, and escrow problems as future GitHub issues. None of these deferred features are implemented in the current codebase.

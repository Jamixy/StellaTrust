# Security Policy

## Supported Versions

This project is a pre-production MVP and is not currently supported for production use.

## Reporting a Vulnerability

Please report security issues privately through the repository maintainers. Do not open a public issue for a security problem.

## Important Notes

- use Stellar Testnet only
- do not commit private keys
- keep secret values in environment variables
- never expose the secret key in frontend or client-side code
- do not use mainnet funds for testing
